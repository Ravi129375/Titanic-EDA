# Titanic Dataset – Exploratory Data Analysis

## Overview
This project performs **Exploratory Data Analysis (EDA)** on the Titanic dataset using Python. The main goal is to understand the dataset, identify patterns, analyze survival rates, and visualize important features.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
The dataset contains information about Titanic passengers, including:

- Passenger ID
- Survival status
- Passenger class (`Pclass`)
- Name
- Sex
- Age
- Number of siblings/spouses (`SibSp`)
- Number of parents/children (`Parch`)
- Ticket
- Fare
- Cabin
- Embarked

## Analysis Performed

### 1. Data Loading & Inspection
- Loaded the dataset using Pandas
- Checked rows and columns
- Inspected data types
- Checked missing values
- Viewed statistical summaries

### 2. Categorical Data Analysis
Analyzed categorical variables such as:
- `Survived`
- `Pclass`
- `Sex`

Used count plots and pie charts to understand the distribution of passengers.

### 3. Numerical Data Analysis
Analyzed numerical variables such as:
- `Age`
- `Fare`
- `SibSp`
- `Parch`

Used histograms and box plots to understand their distributions.

### 4. Data Visualization
Created visualizations using **Matplotlib** and **Seaborn** to identify patterns and relationships within the dataset.

## Key Learning
Through this project, I practiced:
- Data exploration using Pandas
- Handling and identifying missing data
- Understanding categorical and numerical variables
- Creating visualizations
- Performing basic exploratory data analysis
